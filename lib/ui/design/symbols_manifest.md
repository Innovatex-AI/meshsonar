# AppSymbols manifest

Every symbol the redesigned screens may use. Source of truth is `app_symbols.dart`; `test/ui/design/app_symbols_test.dart`
fails when this file and the code disagree. Glyph source (spike S14 default, see app_symbols.dart): CupertinoIcons (MIT) on
Apple platforms, Material Icons (Apache 2.0) on Android. The SF Symbol name is the design intent; no SF Symbols glyph is
redistributed.
