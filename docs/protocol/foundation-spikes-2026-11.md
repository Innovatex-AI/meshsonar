# Shared foundation spikes (WP0, Nov 2 2026)

Run for the Drive plan 15.1 (S1-S5) and chat S14/S9/S10. Measured on the iPhone 17 Pro simulator (iOS 26.5) with
`integration_test/foundation_gallery_test.dart` (prints `SPIKE_*` lines).

| Spike | Result | Evidence | Default taken |
|---|---|---|---|
| S1 offline tile label font | `vector_tile_renderer` passes the first `text-font` entry straight to `TextStyle.fontFamily`. `CupertinoSystemText` (Flutter's alias for the system font) measures identical to the default SF face (231.376 vs 231.376 px for a sample label) and differs from Menlo (286.6). App-target offline style now asks for it (`appLabelFont`, `core/offline_style.dart`). Weight is not carried by the renderer, so bold labels use the regular weight. | `SPIKE_S1` | No Barlow exception needed (D14b NOT invoked). Web glyph stacks stay Barlow (documented). Eyeball real offline labels in the Drive WP5 DR. |
| S2 device baseline | Simulator baseline recorded in `docs/MAP_PERFORMANCE.md` (p95 7.39 ms, worst 21.6 ms). Real phone `unavailable` to devicectl. | MAP_PERFORMANCE.md | Checklist for Andy A1 (HANDOFF 105). `test_driver/integration_test.dart` and `BENCH_REPEATERS` added so the phone run is one command. |
| S3 panel feel / thumb reach | Needs Andy's hands. | - | Checklist (Andy A1). WP3a does not start without it. |
| S4 SF numerals | `FontFeature.tabularFigures()` works on the system font: "1111111111" and "0000000000" are the same width with tnum (214.16 px at 34 pt, 81.88 px at 13 pt) and differ without it. Weight 600 resolves to a distinct face. Flutter's default family does NOT switch SF Text to Display at 20 pt (advance per pt identical at 19.5 and 20.5), so `AppType` requests `CupertinoSystemDisplay` explicitly for sizes >= 20 (hero, large title, title2); tnum on Display is measured in the same run (see log line `SPIKE_S4 display34`). | `SPIKE_S4` | Hero, ring and large numbers use `AppType.hero` / `AppType.num`; no fixed-width digit boxes needed. |
| S5 sprite atlas at 120 Hz | Needs the phone. Prep done: `BENCH_REPEATERS=600` variant of the benchmark, run command in MAP_PERFORMANCE.md. | - | Checklist (Andy A2 / WP5). |
| S14 icons | SF Symbols licence not verified (SF Symbols.app not installed here); chat spikes (PR #132) say do not export SF Symbols into a font or SVG. `AppSymbols` is backed by CupertinoIcons (MIT, already a dependency) on Apple and Material Icons (Apache 2.0) on Android behind a swappable `AppSymbol` API; Lucide/Phosphor SVGs can be added later per symbol (record each licence in `symbols_manifest.md`). | `lib/ui/design/app_symbols.dart` | Open-licence glyphs; no Apple glyph redistributed. |
| S9 avatar initials / mono | `.SF Pro Rounded` and `.SF Mono` render as plain SF Pro (chat spikes). | chat-spikes doc | Initials: system semibold. Mono: Menlo (`AppType.mono`). |
| S10 Reduce Transparency | No Flutter signal. ~10-line native channel `app.meshsonar/accessibility` (`UIAccessibility.isReduceTransparencyEnabled`); `Blur.opaque` is opaque when it reports on, when it is absent, or on Increase Contrast. | `lib/platform/accessibility_channel.dart` | Device check on Andy's phone (toggle in Settings > Accessibility > Display). |
| S8 notification haptics | Channel `app.meshsonar/haptics` compiled in the simulator build; feel needs a phone. | build | Fallback `HapticFeedback` pairs when the channel is missing. |
| S7 sheets | Custom `AppSheetRoute` for medium detents (spring, dim, snap, keyboard growth, 560 max width, drag-to-dismiss that yields to inner scroll), `showCupertinoSheet` for a single detent >= 0.9 on Apple. Widget-tested; drag feel on a phone is a checklist item. | `test/ui/design/app_surfaces_test.dart` | As plan. |
